Counting and location

The total counts distinct EVENT_UNIQUE_ID values across all selected types. Source offence/victim rows and type memberships are preserved, so type counts overlap and must not be added. Main-feed inclusion uses report year; homicide and shooting inclusion uses occurrence year. Dates use Toronto time.

TPS deliberately shifts points to the nearest road intersection for privacy. Published positions are approximate; displacement can affect neighbourhood counts. An incident with differing published positions retains all those points. Each cluster counts distinct IDs; one incident can appear in separate clusters. Missing coordinates remain searchable without a pin.

These preliminary police-reported records can be revised. They do not represent all crime or personal risk. Sexual violations are excluded from the main feed.
